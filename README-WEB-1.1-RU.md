# Code Security Analyzer — Web 1.1

Обновление поверх уже установленной Web 1.0. Desktop JavaFX, темы v1–v8 и GitHub не меняются.

## Функции
- загрузка до 5 одиночных файлов или одного ZIP проекта (2 МБ на архив);
- ZIP: максимум 30 исходников, 256 КБ на файл, 1 МБ исходников в сумме, 200 записей, 4 МБ распакованных данных;
- дерево путей и просмотр исходного кода с номерами строк;
- подсветка строк отдельной находки LLM или Semgrep;
- отдельная диагностика частичного LLM-анализа;
- JSON-экспорт БЕЗ содержимого исходных файлов;
- анимация процесса анализа (не показывает вымышленный процент).

Не является публичным сайтом. Сервер по умолчанию слушает 127.0.0.1:8080; для доступа с телефона в одной сети нужна отдельная LAN-настройка. Не публикуйте сервис в открытый интернет без авторизации и изоляции.

## Установка
1. Закройте сайт и JavaFX. Распакуйте ZIP в корень проекта рядом с pom.xml.
2. Откройте PowerShell и выполните:

```powershell
cd "E:\001 Satbayev University\diplom\Новая папка\code-security-analyzer"
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-21.0.12.101-hotspot"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
.\.venv-semgrep\Scripts\python.exe .\apply_web_v11.py
.\mvnw.cmd clean test
powershell -NoProfile -ExecutionPolicy Bypass -File .\run-web.ps1
```

3. Перейдите на http://127.0.0.1:8080 и обновите страницу Ctrl+F5, поскольку браузер мог закэшировать web.js/web.css.
4. Проверьте сначала Case008.java, затем небольшой ZIP с тестовым Java/Python-проектом.

## Важно
Веб-предпросмотр пересылает исходный код обратно в локальный браузер; экспорт JSON удаляет поле source.
Проверка JavaFX Fix Validation Agent не переносилась в веб-интерфейс.
Нельзя заключать, что код безопасен, только по отсутствию находок.
В ZIP нельзя помещать секреты и персональные данные. Папки .git, .venv, node_modules и т. п. игнорируются.
Разбор ZIP не выполняет файлы. Результаты LLM могут быть частичными или ошибочными.

## Проверка
Доступные проверки разработчика: синтаксис JS, standalone Java тесты политики ZIP, проверки установщика.
Полная Maven-сборка и Windows-browser UI должны быть подтверждены на пользовательском ПК.
