# Code Security Analyzer 9.0 RC1 — UI Polish 2: чаты, Dashboard и таблица

Предназначено для проекта, где **уже установлен** предыдущий патч
`Code_Security_Analyzer_UI_Themes_Responsive_9.0_RC1.zip`.

## Что нового

1. Три компактных карточки в «Анализ кода»: **файлов в дереве**, **находок в текущей таблице**, **HIGH/CRITICAL в текущей таблице**. Значения обновляются по реальным данным интерфейса; это не «проверено» и не доказательство безопасности.
2. В тёмной теме WebView-чаты получают тёмный фон, контрастные сообщения пользователя, ИИ и системы; при смене темы оформление меняется без удаления истории.
3. Таблица вместо «No content in table» показывает локализованную заглушку и пояснение ограничений пустого результата. Категория severity отображается как компактный цветной индикатор.
4. Нижняя статусная полоса показывает выбранную модель и **число находок именно в текущей таблице**. Статус Semgrep следует смотреть в его отчёте, индикатор не притворяется онлайн-мониторингом.
5. Остаётся прежняя адаптивная компоновка с переносом кнопок и темами. Не изменяются исходные Java-кейсы, сервисы, LLM, результаты и CI.

## Установка на Windows PowerShell

1. Закрыть запущенное окно Code Security Analyzer.
2. Распаковать **содержимое ZIP** в корень рабочего проекта, рядом с `pom.xml`.
3. Запустить:

```powershell
cd "E:\001 Satbayev University\diplom\Новая папка\code-security-analyzer"
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-21.0.12.101-hotspot"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
.\mvnw.cmd -version
.\.venv-semgrep\Scripts\python.exe .\apply_ui_dashboard_patch.py
.\mvnw.cmd clean test
```

4. Запустить проект в IntelliJ IDEA (JDK 21), проверить:
   - после запуска в тёмной теме HTML-окно диалога тоже тёмное;
   - добавление сообщения и переключение тем перекрашивает сообщения, не очищая их;
   - до анализа заглушка таблицы не означает «код безопасен»;
   - при выборе папки меняется число файлов; при выборе файла после сканирования — число находок и HIGH;
   - индикатор severity отображается в строках с HIGH/MEDIUM/LOW;
   - при ширине 900 / 650 px три карточки переносятся, ничего не перекрывается;
   - после перезапуска сохраняется выбранная тема.

## Безопасность, откат и GitHub

- Установщик **не** работает напрямую с Git и не отправляет ничего в сеть.
- При несоответствии предыдущих CSS-файлов известным версиям патч **не перезаписывает** собственные изменения.
- Исходники, которые заменяются, сохраняются в `ui-theme-backup/<дата>-dashboard`.
- Чтобы откатить, из резервных копий вернуть `JavaFxApplication.java`, `light-theme.css`, `dark-theme.css`; удалить новые `UiDashboardEnhancer.java`, `web-light.css`, `web-dark.css`, если они не изменялись вручную.
- Для переноса в чистый GitHub-клон после **успешных** тестов скопируйте только 6 изменённых/новых файлов из `src/main` (JavaFxApplication, UiDashboardEnhancer, два JavaFX CSS и два WebView CSS). Не добавляйте `ui-dashboard-files`, установщик и резервные копии.

**Ограничение проверки:** патч прошёл проверки файлов/идемпотентности и ручную статическую оценку, но JavaFX-окно и Maven-тесты на Windows должен запустить разработчик. UI/UX не влияет на реальный security verdict.
