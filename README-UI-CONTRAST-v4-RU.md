# Code Security Analyzer — UI Contrast Repair v4

Небольшой патч для пользовательского интерфейса, установленного через UI Themes (v1), Dashboard (v2) и Icons Polish (v3). Не затрагивает Semgrep, Ollama, Fix Agent, логику анализа, учебные данные и результаты тестов.

## Что исправляется

1. Текст имён файлов/папок в `TreeView` перестаёт принудительно окрашиваться в тёмно-синий цвет (`#2c3e50`). Цветом управляет выбранная тема. Оформление находок красным/зелёным сохраняет текущая обёртка `UiAppearanceManager`.
2. Стили чата встраиваются прямо в HTML до вызова `WebEngine.loadContent(...)`: белая область `WebView` в тёмной теме должна исчезнуть и при пустом чате. Переключение темы повторно применяет HTML-стили.
3. При появлении окна после инициализации JavaFX Skin дополнительно назначается русская заглушка пустой таблицы.
4. В тёмной теме обновляется контрастность надписи «Выделить всё».

## Установка

1. Закройте приложение JavaFX.
2. Распакуйте **всё содержимое** ZIP в корень `code-security-analyzer`, рядом с `pom.xml`, сохранив дерево `ui-v4-files`.
3. В PowerShell:

```powershell
cd "E:\001 Satbayev University\diplom\Новая папка\code-security-analyzer"
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-21.0.12.101-hotspot"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
.\.venv-semgrep\Scripts\python.exe .\apply_ui_contrast_v4.py
.\mvnw.cmd clean test
```

4. После `BUILD SUCCESS` запустите приложение обычным способом. Проверьте, что:
  - у файлов в дереве видны названия в обеих темах;
  - чат тёмный при выборе «Тёмная» и светлый в «Светлая»;
  - вместо `No content in table` отображается русская подсказка;
  - выделение файлов, кнопки анализа и существующие отчёты работают как раньше.

## Откат

Установщик сохраняет исходные `JavaFxApplication.java` и `MainController.java` в папку `ui-theme-backup/<время>-contrast-v4`. Если что-то не работает, закройте приложение и скопируйте их обратно из **конкретной созданной** папки резервного копирования, затем удалите только новый `src/main/java/com/analyzer/ui/theme/UiContrastRepair.java` при необходимости. Не удаляйте `.git`, исходники, `fix-validation` или другие материалы проекта.

## Ограничения

- Исправление проверено на структуре и точных точках подключения трёх предыдущих UI-архивов, но **не прошло** Maven-сборку и GUI-тестирование на компьютере пользователя.
- При ручных изменениях `MainController.java` или `JavaFxApplication.java` установщик остановится, если не найдёт ожидаемые точные строки; он не будет угадывать и применять изменения в другой код.
- Код и CSS генерируются в UTF-8 **без BOM**.
- Патч является локальным и не отправляет ничего на GitHub.
