# Code Security Analyzer — Web 1.4: Audit History & Insights

Обновление устанавливается **поверх Web 1.3**, не изменяет JavaFX, Spring Boot API, Ollama, Semgrep, Fix Recommendation и Fix Validation.

## Что нового

1. **02.A / Аналитика текущего аудита** — графики по тяжести сигналов (HIGH / MEDIUM / LOW) и указанным анализаторами CWE. Это счётчики *сигналов*, а не подтверждённых уязвимостей.
2. **Предполагаемые совпадения LLM + Semgrep** — отдельная подсказка, когда оба инструмента указывают на похожую категорию и близкие строки **одного и того же файла**. Первичные сигналы остаются в таблице неизменными. Нажатие на кнопку открывает каждую исходную находку по отдельности. Близость строк не означает подтверждение уязвимости или дубля.
3. **06 / История аудитов** — до 60 последних попыток, включая неудачные, хранятся в localStorage текущего браузера. Поля: дата, модель, тип загрузки, количество файлов, сигналов, HIGH, статистика LLM, состояние Semgrep, число диагностик, количество предполагаемых пар. **Исходники, предложения, тексты диагностик и пути к файлам не сохраняются.**
4. **Экспорт истории CSV и JSON** — для отчётов и дипломных таблиц. CSV защищён от интерпретации пользовательских строк как формул.
5. **HTML-отчёт для печати** — новая кнопка «HTML-отчёт для PDF» в панели результатов. Скачивает самодостаточный HTML отчёт с таблицей сигналов и сводными показателями, **без исходников и предложенного кода**. Открой файл в Chrome/Edge, затем `Ctrl+P` → «Сохранить как PDF».

История генерации исправлений Web 1.3 продолжает работать отдельно; её прежние записи не удаляются. Прошлые аудиты до установки Web 1.4 автоматически не восстанавливаются.

## Установка (Windows 11 / PowerShell)

1. Закрой веб-сервер нажатием `Ctrl+C` в окне, где работает `run-web.ps1`.
2. Распакуй содержимое этого ZIP **в корень** `code-security-analyzer`, рядом с `pom.xml`. Не удаляй старые файлы и ZIP-патчи.
3. В новом PowerShell:

```powershell
cd "E:\001 Satbayev University\diplom\Новая папка\code-security-analyzer"
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-21.0.12.101-hotspot"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"

.\.venv-semgrep\Scripts\python.exe .\apply_web_v14.py
.\mvnw.cmd clean test

powershell -NoProfile -ExecutionPolicy Bypass -File ".\run-web.ps1"
```

4. Открой `http://127.0.0.1:8080` и обнови страницу с `Ctrl+F5`. Вверху должна быть надпись `Web 1.4`.
5. Для проверки загрузки проекта открой `benchmark-dataset/java/Case008.java` и `Case011.java` (или архив с ними), запусти анализ, затем найди `02.A / АНАЛИТИКА` и `06 / ИСТОРИЯ АУДИТОВ`. Фактические результаты LLM могут отличаться в разных запусках.
6. Нажми «HTML-отчёт для PDF» вверху блока «Находки и проверка», скачай `code-security-web14-report.html`, открой его в браузере и выбери «Печать» → «Сохранить как PDF».

### Если установка остановилась

Установщик сверяет SHA-256 локальных файлов с **точной** версией Web 1.3, которую мы ранее устанавливали. Если пользовательские изменения затронули `index.html`, `web.js` или `web.css`, установщик остановится **до записи**, чтобы не затереть их. Отправь вывод `ОСТАНОВЛЕНО` для точечного исправления. Переустанавливать всё подряд не нужно.

Резервные копии изменяемых файлов находятся в `web-v14-backup/<дата>/...`. Повторная установка ничего не дублирует.

### Проверки в архиве (если есть Node.js)

```powershell
node .\web14-tests\test_web_insights.cjs
node --check .\src\main\resources\static\web-insights.js
node --check .\src\main\resources\static\web.js
```

Это Web UI/JS-тесты. Полная Maven-сборка и визуальная проверка должны быть подтверждены на локальном Windows-компьютере пользователя.

## Ограничения и безопасность

- Веб-приложение **только локальное** (`127.0.0.1`), без публичной авторизации; его пока нельзя открывать для всей сети/интернета.
- Результаты LLM и Semgrep могут быть ложными или неполными. Совпадение сигналов — только подсказка, а не подтверждение уязвимости.
- История — **только** в браузере/профиле и на данном устройстве. Очистка данных сайта может удалить её; экспортируй CSV/JSON для резервной копии.
- CSV/JSON истории не содержат исходников и подробных данных находок; HTML-отчёт содержит имена файлов и метаданные обнаруженных сигналов, но **не текст исходного кода**. Не делись отчётами без проверки их содержания.
- Проверка предложенных Java-исправлений и журнал ручных функциональных тестов продолжают работать как в Web 1.3.
- Исполнять пользовательский код эта версия не будет. Реальные функциональные испытания по-прежнему выполняются отдельно в контролируемом окружении.
