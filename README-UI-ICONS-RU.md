# Code Security Analyzer — UI Icons Polish v3

Обновление для Code Security Analyzer 9.0 RC1, поверх **ранее установленных** двух UI-патчей:
`UiAppearanceManager` (Light/Dark + адаптивная раскладка) и `UiDashboardEnhancer` (карточки, WebView, статусы).

## Что меняется

- Единый набор **векторных SVGPath-иконок JavaFX** для действий, вкладок, выбора темы, дерева файлов, карточек и статусной строки. Нет emoji-зависимости и внешних библиотек.
- Вместо стандартного значка JavaFX — собственная PNG-иконка окна.
- Русские короткие подписи на кнопках без символов, которые иногда плохо показываются в Windows.
- Плавное, сдержанное изменение масштаба кнопок при наведении, не трогая их `onAction`.
- Tooltip у действий. Улучшенный пустой экран результатов и оттенки при наведении.
- Все новые элементы работают со светлой и тёмной темами и ранее реализованной адаптивной раскладкой.

**Принцип:** никакие LLM-агенты, Semgrep, Java/Fix Validation, отчёты, benchmark, CI и исходники учебных кейсов не изменяются. История экспериментов и репозиторий Git не меняются. Только визуальное оформление.

## Установка в Windows PowerShell

1. Закройте JavaFX-приложение. Не распаковывайте в чистый GitHub-клон: сначала проверяем в рабочей папке.
2. Распакуйте **содержимое ZIP** (два элемента `apply_ui_icons_polish.py` и `ui-icons-files`) в корень `code-security-analyzer`, где находится `pom.xml`.
3. Откройте PowerShell и выполните:

```powershell
cd "E:\001 Satbayev University\diplom\Новая папка\code-security-analyzer"
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-21.0.12.101-hotspot"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
.\.venv-semgrep\Scripts\python.exe .\apply_ui_icons_polish.py
.\mvnw.cmd clean test
```

4. После `BUILD SUCCESS` запустите JavaFX-приложение из IntelliJ IDEA с JDK 21. Проверьте четыре вкладки, обе темы, уменьшение/увеличение окна, дерево файлов с чекбоксами и кнопку анализа.
5. Если таблица по-прежнему показывает английскую подпись или иконки не отображаются, пришлите скриншот и консольный лог запуска — тогда исправим точечно.

## Безопасная установка

Установщик предварительно проверяет `pom.xml`, наличие обоих старых UI-слоёв и контрольные суммы старых CSS. Он **откажется менять** CSS-файлы, если вы их уже правили вручную или если они отличаются от установленной версии Dashboard v2.

Прежде чем заменять файлы, установщик сохраняет их в `ui-theme-backup\<timestamp>-icons-v3\...`. При ошибке записи выполнит откат. Повторный запуск того же патча безопасен: не создаёт новые изменения.

Проверить успешный импорт и вызов можно так:

```powershell
Select-String -Path '.\src\main\java\com\analyzer\JavaFxApplication.java' -Pattern 'UiIconPolish'
```

## Ограничения

- Это UI-патч для **предполагаемой структуры установленного v1/v2** на вашем компьютере; не проверен на других форках.
- Успешный `clean test` проверяет сборку/тесты, но не гарантирует безупречный внешний вид в Windows: нужна ручная визуальная проверка.
- Локально перед выдачей протестирована установка на имитации предыдущих двух UI-патчей, повторная установка, проверка конфликтов и синтаксис нового файла. Полный запуск JavaFX на вашем компьютере пока не выполнен.
- Не присваивайте всему приложению статус «9.0 stable» только за визуальные изменения — технические release-gates остаются отдельными.
