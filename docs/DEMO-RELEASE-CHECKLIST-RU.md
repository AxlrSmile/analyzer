## Проверка Web 1.8 от 27 ноября 2026 года

Локальный сервер вернул HTTP 200 для главной страницы. Через `/api/scan` загружен `web-demo/Case008.java` с моделью `qwen2.5-coder:7b`. Обработан один файл, LLM завершила анализ и указала CWE-89. Semgrep выдал один сигнал. Диагностик сканирования не было.

Через `/api/fix-preview` получен новый вариант. Компиляция и проверка API прошли, результат Semgrep изменился с 1 до 0. SHA-256 предложения в UTF-8 с переводами строк LF — `5e74c99f1d971adafc112f9eaff69789392088e013b78ba5bc7f191f03035136`. Функциональные тесты H2 относятся к ранее сохранённому варианту. В этом прогоне проверены HTTP-интерфейс, компиляция, API и статический анализ.
