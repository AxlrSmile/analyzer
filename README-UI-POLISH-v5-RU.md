# Code Security Analyzer — UI Polish v5

Патч применяется **поверх** UI Theme/Responsive v1, Dashboard v2, Icons v3,
Contrast Repair v4. Не устанавливайте прямо на чистый GitHub-клон.

## Что исправлено

1. В дереве исходников появились поиск и флажок «Только исходники».
   Поиск находит имена файлов и папок, без учёта регистра. В режиме исходников
   показываются разрешённые расширения исходных файлов и скрываются служебные
   каталоги (`.git`, `target`, `fix-validation`, `ui-theme-backup` и т. д.).
2. Счётчик «Файлов в дереве» считает **отображаемые реальные файлы**, а не
   завершённые анализы. Число 0 не означает, что код проверен и безопасен.
3. В сообщении о выборе проекта удалён эмодзи, отображавшийся в WebView
   испорченными символами. Весь остальной текст и результаты сохранены.
4. Подправлены контраст светлой темы, оформление поиска и разделителей панелей.
   Минимальный размер главного окна — 700×560; панели по-прежнему можно
   изменять перетягиванием разделителя SplitPane.

## Важная особенность фильтра и выбора файлов

**При включённом поиске или фильтре анализируются только отмеченные файлы,
которые отображаются в дереве.** Скрытые файлы не удаляются с диска, а
исходные отметки чекбоксов сохраняются. После сброса поиска дерево
возвращается к исходному виду. Это не поиск по содержимому кода.

Для полного анализа сначала сбросьте поиск и фильтр, затем отметьте все
нужные исходники. При выборе папки для сканирования лучше выбирать отдельную
папку проекта или `benchmark-dataset/java`, а не весь репозиторий вместе с
отчётами и резервными копиями.

## Установка

1. Закройте JavaFX-приложение.
2. Распакуйте **содержимое** ZIP в корень `code-security-analyzer`, рядом с
   `pom.xml`. Из ZIP должны появиться `apply_ui_polish_v5.py`, `ui-v5-files/`,
   этот README.
3. Запустите в PowerShell:

```powershell
cd "E:\001 Satbayev University\diplom\Новая папка\code-security-analyzer"
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-21.0.12.101-hotspot"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
.\.venv-semgrep\Scripts\python.exe .\apply_ui_polish_v5.py
.\mvnw.cmd clean test
```

4. Запустите приложение через IntelliJ IDEA с JDK 21.

## Проверка

- Откройте корень проекта: счётчик должен показывать число файлов, реально
  отображаемых в дереве.
- Введите `Case008` в поле поиска, убедитесь, что виден нужный файл.
- Включите «Только исходники»; файлы `.csv`/`.pdf` и резервные каталоги
  должны исчезнуть из **представления**, но остаться на диске.
- Проверьте, что отметка выбранного файла остаётся после очистки поиска.
- Уменьшите окно до 700–850 px и затем разверните; разделитель панелей
  можно перетаскивать.
- Переключите светлую/тёмную тему. Убедитесь, что текст фильтра читаемый.
- Проверьте системное сообщение «Загружен проект» без повреждённых знаков.

## Границы изменений

Установщик меняет только `JavaFxApplication.java`, одну приветственную строку
`MainController.java`, добавляет `UiPolishV5.java` и два CSS-файла. Исходники
проверяемых проектов, LLM, Semgrep, экспериментальные данные, CI и отчёты он
не изменяет. Перед изменениями создаёт копии файлов в `ui-theme-backup/`.
Если файлы уже изменены вручную или установлен не тот набор v1–v4, установка
останавливается вместо принудительной перезаписи.
