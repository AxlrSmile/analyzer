# UI Filter v8 — устранение NullPointerException

**Для Code Security Analyzer с уже установленными UI v1–v7.**

## Причина

`UiPolishV5` искал `TreeView` слишком рано. Если дерево ещё не было доступно, поле `fileTree` оставалось равным `null`. Патч v7 вызывал `createFilterControls()` через `Platform.runLater` без дополнительной проверки, из-за чего в JavaFX Application Thread возникал `NullPointerException`.

## Исправление

- Поиск `fileTreeView` после появления окна; используется поиск по FXML id, CSS id и безопасный резервный поиск, только если дерево в окне единственное.
- Фильтр подключается лишь тогда, когда `TreeView` реально найден.
- При отсутствии дерева приложение не падает: фильтр пропускается с диагностикой в консоли.
- Защита от повторной инициализации слушателей.
- Логика Semgrep, Ollama, отчетов и обработки Java-кода не меняется.

## Установка

1. Закройте приложение JavaFX.
2. Распакуйте **содержимое** ZIP в корень `code-security-analyzer` рядом с `pom.xml`.
3. PowerShell (из корня проекта):

```powershell
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-21.0.12.101-hotspot"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
.\.venv-semgrep\Scripts\python.exe .\apply_ui_filter_v8.py
.\mvnw.cmd clean test
```

После `BUILD SUCCESS` запустите JavaFX, выберите папку проекта и убедитесь, что над деревом есть поле `Поиск файла или папки...`, переключатель `Только исходники` и счётчик видимых файлов. Проверьте поиск по `Case008` и включение/выключение фильтра.

### Если версия не совпала

Установщик намеренно **не меняет** чужой или вручную измененный `UiPolishV5.java` и сообщает об этом. Приложите исходный Java-файл для безопасной адаптации. **Не запускайте старый установщик v7 повторно.**

### Если необходимо откатить

Скопируйте файл `UiPolishV5.java` из папки `ui-theme-backup/*-filter-v8/` обратно в `src/main/java/com/analyzer/ui/theme/`, предварительно закрыв JavaFX. Используйте именно путь к резервной копии, который напечатал установщик.

Тестирование: проверен установщик на эталонном тексте v7, повторная установка и отклонение конфликта. **Полноценная компиляция и визуальная проверка JavaFX выполняются на компьютере пользователя**.
