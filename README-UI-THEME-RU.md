# Code Security Analyzer 9.0 RC1 — темы и адаптивное окно JavaFX

## Что добавляет патч

- Переключатель `Тема: Светлая / Тёмная` над вкладками; выбор сохраняется через `java.util.prefs.Preferences`.
- JavaFX CSS для светлой и тёмной темы: панели, вкладки, поля, таблицы, дерево, кнопки.
- Главные панели действий (`Анализ кода`, `Чат с ИИ`, `Бенчмарк`) используют `FlowPane`: кнопки автоматически переносятся при сужении окна.
- Кнопки главного сканирования динамически подстраивают ширину по доступному месту.
- На узком окне дерево файлов и область результатов располагаются друг под другом (`SplitPane` меняет ориентацию).
- Колонки основной таблицы заполняют доступную ширину.
- Для трёх встроенных WebView применяется соответствующий фон и базовые цвета HTML.
- Отдельные диалоги при открытии получают выбранную JavaFX тему; **кастомная HTML/inline-стилизация отдельных диалогов может сохранять собственные цвета**.

Не изменяются сервисы Semgrep, LLM, Fix Validation, учебные кейсы, скрипты и отчёты.

## Установка в Windows PowerShell

1. Распаковать **содержимое ZIP** в корень рабочего проекта `code-security-analyzer` **рядом с `pom.xml`**; должна появиться `apply_ui_theme_patch.py` и папка `ui-theme-files`.
2. В PowerShell выполнить:

```powershell
cd "E:\001 Satbayev University\diplom\Новая папка\code-security-analyzer"

# Один раз, безопасно и с резервной копией JavaFxApplication.java:
.\.venv-semgrep\Scripts\python.exe .\apply_ui_theme_patch.py

# Повторная проверка Java:
.\mvnw.cmd clean test

# Показать изменённые файлы в Git:
git status --short
```

3. Запустить приложение своим обычным способом (через IntelliJ / `CodeSecurityAnalyzerApplication`). Выбрать тему сверху, уменьшить и увеличить окно на каждой вкладке, проверить работу кнопок.
4. При необходимости перезапустить приложение: выбранная тема должна сохраниться.

**ВАЖНО:** не копировать `ui-theme-files`, резервные копии или временные экспериментальные файлы в чистый GitHub-клон. После успешной проверки перенести **только 4 файла** в `analyzer-author-fix`:

- `src/main/java/com/analyzer/JavaFxApplication.java` (изменён);
- `src/main/java/com/analyzer/ui/theme/UiAppearanceManager.java` (новый);
- `src/main/resources/styles/light-theme.css` (новый);
- `src/main/resources/styles/dark-theme.css` (новый).

И только затем запускать Maven, просматривать `git diff` и коммитить. Проект и GitHub автоматически патчем **не изменяются**.

## Ограничения и проверки

- Патч подготовлен по версии репозитория `AxlrSmile/analyzer`, коммит `290798d031fa9ac9c33ce2dbc86985b4f68a1dec`.
- Ручной просмотр критичен: примерный минимум окна — 640×520, на очень низких экранах может понадобиться прокрутка отдельных панелей.
- Некоторые элементы, которые контроллер перекрашивает динамически (например, индикаторы статуса файлов), могут сохранить свой прежний цвет; их стоит проверить в обеих темах.
- Связанный JavaFX CSS и смена ориентации панели **не меняют результаты анализа и исходники**.
- **JavaFX runtime и Maven-тесты здесь не запускались**; проверку выполнить на вашей Windows-машине по командам выше.

## Если нужно откатить

Верните `JavaFxApplication.java` из папки `ui-theme-backup/<дата>/`, затем удалите три новых файла `UiAppearanceManager.java`, `light-theme.css`, `dark-theme.css`. Сначала проверьте, что в них нет собственных правок. Если работаете в чистом Git-клоне, можно откатить изменения средствами Git, но не удаляйте пользовательские файлы без проверки.
