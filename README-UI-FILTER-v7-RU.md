# Code Security Analyzer — UI Filter Recovery v7

Точечное восстановление элементов поиска и «Только исходники», добавляемых программно классом `UiPolishV5`, **не через FXML**. Поэтому отсутствие `Только исходники` в `main-view.fxml` не является ошибкой.

## Изменения

- Гарантирует ровно один вызов `UiPolishV5.install(primaryStage, root)` в `JavaFxApplication.java`.
- Делает вставку фильтра устойчивее к дополнительным контейнерам JavaFX между `TreeView` и `VBox`.
- Повторяет установку фильтра после отображения окна, если первый вызов произошёл до готовности layout.
- Не изменяет FXML, SAST/LLM, пользовательские файлы, датасет, `pom.xml`, Git или результаты тестов.
- Создаёт резервную копию каждого изменяемого файла, безопасен при повторном запуске. Сохраняет исходники в UTF-8 без BOM.

## Установка

Закройте JavaFX. Распакуйте ZIP **содержимым** рядом с `pom.xml`. В PowerShell:

```powershell
cd "E:\001 Satbayev University\diplom\Новая папка\code-security-analyzer"
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-21.0.12.101-hotspot"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
.\.venv-semgrep\Scripts\python.exe .\apply_tree_filter_v7.py
.\mvnw.cmd clean test
```

## Проверка

```powershell
Select-String -Path '.\src\main\java\com\analyzer\JavaFxApplication.java' -Pattern 'UiPolishV5.install'
```

После запуска на вкладке «Анализ кода» над деревом должны появиться поле «Поиск файла или папки...» и переключатель «Только исходники». Введите `Case008`, затем включите и отключите «Только исходники». Фильтр управляет видимыми/выбранными файлами для анализа, не удаляя файлы с диска.

**Не путайте UI-фильтр с безопасностью анализа:** он не подтверждает, что Semgrep или LLM обработали скрытые или видимые файлы. Состояние сканирования проверяйте отдельно.

Если установщик останавливается из-за изменённого `UiPolishV5.java`, не перезаписывайте его вручную; используйте сохранённые резервные копии и проверяйте конфликты изменений.
